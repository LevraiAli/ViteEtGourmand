![Version](https://img.shields.io/badge/ViteEtGourmand-0.0.1-blue)  
## Project Overview  
**Vite & Gourmand** is a web application about a restaurant, to display it's menu, allow to order online, to review it and for it's employees to update the menu and its items.  
This project is built for a Studi homework  
This project uses the following gitflow :  
 - branch main for the production
 - branch develop for all developpement to merge in main
 - branch feature/ticket to merge to develop for each feature
